Champ de texte multiligne : le texte facultatif d'une entrée (RM13).

- **Fournit** : le libellé, le texte d'exemple, la valeur et le rappel au changement.
- **Rendu** : libellé `label` en `ink-muted` au-dessus, champ `surface-raised`, bordure `line`, rayon `radius-sm`, texte `body`. Sous le champ, la mention de confidentialité en `caption` avec une icône de cadenas.
- **À éviter** : un compteur de caractères anxiogène, un texte d'exemple qui suggère quoi ressentir.
