Mention de chargement : dit que le modèle travaille, sur le téléphone.

- **Fournit** : la phrase, qui nomme l'action (« Analyse en cours sur ton téléphone… », « Préparation du modèle… »).
- **Rendu** : indicateur circulaire en `tide`, texte `label` en `ink-muted`. La rotation s'arrête quand le téléphone demande de réduire les animations. Annoncé au lecteur d'écran (`status`).
- **Usage** : chargement du modèle en arrière-plan (jusqu'à 12 s au premier chargement, ADR-001), analyse d'une entrée. Jamais de squelette clignotant.
