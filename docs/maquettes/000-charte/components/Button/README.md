Bouton : une action, nommée par ce qu'elle fait.

- **Fournit** : le libellé (un verbe : « Enregistrer », « Tout supprimer »), la variante et l'action.
- **Variantes** : principal (`tide`, texte `on-tide`, un seul par écran) ; secondaire (bordure `line`, texte `tide`) ; destructif (bordure et texte `danger`, réservé à la suppression totale, toujours suivi d'une confirmation) ; désactivé et en cours (bordure `line`, texte `ink-muted`, indicateur pour « en cours »).
- **Mesures** : hauteur 52 px (au-dessus de `tap-min`), rayon `radius-pill`, `label` à 16 px.
